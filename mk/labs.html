Во приватен развој.

Шест проекти во приватна бета — добредојдени се прашања за ран пристап ако имате реален случај на употреба. Ќе пратам кратко објаснување и NDA ако има смисла.

  • CBE Course Development Pipeline

    WGU-стил CBE pipeline за развој на курсеви. Компетенции → evidence statements → LOs → task модели → PA prompts → DOCX. 7-pass квалитетна ревизија вградена.

    Распрашајте се →

  • Classroom of Tomorrow

    LMS со ВИ и 7 специјализирани агенти што водат сократски разговори со учениците. Monorepo: Next.js 14 + Hono API + Anthropic Claude + Drizzle/Postgres.

    Распрашајте се →

  • SurveyStudio

    Full-stack платформа за анкети и оценување со ставки генерирани од ВИ и анализа. Next.js 15 frontend, Django REST backend, Flask AI сервис со RAG.

    Распрашајте се →

  • CourseBuilder

    ВИ платформа што генерира комплетни Coursera кратки курсеви од blueprint-и од високо ниво. 20+ типови содржина — скрипти, квизови, HOL-ови, рубрики, слајдови. Flask, ~4,200 теста.

    Распрашајте се →

  • CalendarHub

    Tauri 2 десктоп апликација што ги обединува Google Calendar и Office 365 во еден локален интерфејс. SQLite, OAuth 2.0, OS keychain. React 19 + Rust.

    Распрашајте се →
